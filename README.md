# 🧩 General Heading Component

A reusable and scalable **Typography / Heading component** built with React + TypeScript.

This component standardizes heading usage (`h1`, `h2`, `h3`) across projects and enforces visual consistency by splitting styles into semantic categories:

- `PRIMARY`
- `SECONDARY`
- `TEXT`
- `DETAIL_TEXT`

Designed for use in shared UI libraries, micro frontends, and scalable design systems.

---

## ✨ Features

- Supports `h1`, `h2`, `h3`
- Semantic category-based styling
- Fully typed with TypeScript
- Easy to extend
- Design-system friendly
- Micro-frontend safe
